# Veridion

**An Explainable AI Platform for Scam Detection and Cybersecurity Education**

Veridion is an AI-powered web application that helps users identify phishing emails, SMS scams, malicious URLs, and social engineering attacks while explaining the reasoning behind every investigation. Rather than acting as a black-box classifier, Veridion uses an explainable, evidence-based investigation engine that highlights suspicious signals, estimates confidence, and provides actionable recommendations to help users make informed decisions.

Beyond detection, Veridion serves as an interactive digital safety learning platform. Users can complete structured lessons, practice with realistic scam scenarios, measure their knowledge through Scam IQ assessments, and track their progress over time. The investigation engine is supported by an automated benchmarking framework evaluated on 678 labeled samples, achieving **96.2% Accuracy**, **100.0% Precision**, **92.7% Recall**, and a **0.0% False Positive Rate** through a transparent, reproducible evaluation pipeline.

## Features

- Explainable AI investigation engine for emails, SMS messages, URLs, and screenshots
- Evidence-based risk scoring with confidence calibration and actionable recommendations
- Interactive cybersecurity curriculum with adaptive practice and Scam IQ assessments
- Automated benchmarking and regression testing framework with reproducible evaluation reports
- Modern React + TypeScript interface focused on accessibility, transparency, and education
